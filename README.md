# 🍺 The Bar Graph

> Find the best bars and restaurants in your city — plotted by vibe and food quality.

Live at **[bargraph.city](https://bargraph.city)**

## What is this?

The Bar Graph is an interactive scatter plot that maps local bars and restaurants across two axes:
- **X axis**: Sketchy → Classy
- **Y axis**: Just Drinks → Destination Dining

Circle size = average drink price. Filter by type: sports bar, pizza, Mexican, Italian, and more.
